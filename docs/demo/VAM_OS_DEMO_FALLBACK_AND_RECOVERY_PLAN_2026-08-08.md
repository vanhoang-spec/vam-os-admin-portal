# VAM OS Demo Fallback and Recovery Plan — 8 August 2026

Fallback order: **live preview → second browser/incognito → verified local build → approved prepared screenshots/video → presentation-only walkthrough**.

| Failure | Immediate response | Abort/escalate condition |
|---|---|---|
| Preview unavailable | retry once; switch incognito/local | target unexpectedly production |
| Database unavailable | stop writes; use static fallback | data integrity/security warning |
| Login failure | verify correct placeholder account privately; switch role/account | repeated auth or scope anomaly |
| Stale deployment | compare displayed/recorded commit; use pinned local build | commit cannot be proven |
| Missing demo data | do not seed ad hoc; use screenshots/table | any temptation to use real data |
| Browser cache | hard refresh/incognito | persists across clean browser |
| Remote access/network | local build then offline assets | no safe fallback available |
| Route error | use adjacent verified route/static walkthrough | error exposes internals/data |
| Accidental production navigation | close tab immediately; report; verify no action occurred | any click/write or personal data exposure |

Before demo cache a local build and only repository-approved synthetic assets. No screenshots/video are generated by this package.
