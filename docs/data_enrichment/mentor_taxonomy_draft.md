## Review Rules

- Select all meaningful values, not just the mentor's current job.
- Use `primary_industry` and `primary_function` only as dashboard defaults.
- Use `Needs Review` only when the label itself is unclear.
- Use `confidence = needs_review` when the reviewer needs another human decision.
