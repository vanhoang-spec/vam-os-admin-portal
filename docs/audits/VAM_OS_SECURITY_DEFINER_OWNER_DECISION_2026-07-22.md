`SET search_path = public` is observed but not the recommended final hardening by itself. Owner should choose between fully qualifying all catalog/application objects with a minimal `pg_catalog, public` path, or setting an empty path and qualifying every object. `anon` does not need execute for admin helpers/RPCs. `service_role` access alone does not replace application caller validation. None of the seven writes rows; dashboard results may expose sensitive operational aggregates and require role/program/season enforcement.
